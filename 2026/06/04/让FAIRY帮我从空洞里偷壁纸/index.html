我让 FAIRY 从空洞里帮我偷壁纸，每月自动更新

2026/6/4 游戏 绝区零 Python 自动化 Agent 壁纸

作为一个绝区零老玩家，我对游戏里的美术一直是服气的。每次新版本的角色立绘、剧情 CG、活动壁纸，质量都高到想全部存下来当桌面。

但问题是——米游社的壁纸散落在各个页面里，每次手动去找、右键保存、整理文件夹，太原始了。我是做数据开发的，这种事不做第二遍。

于是我把目光投向了米游社绝区零 Wiki 的 API，结合 AI Agent 的定时任务能力，搞了一套全自动的壁纸抓取 + 更新 + 通知系统。

而且，既然绝区零里有 FAIRY 这个超级智能体，那我就让 FAIRY 来干这活。

整体思路

系统分三层：

  1. 数据层：Python 脚本负责从米游社 API 抓取壁纸元数据、比对本地已有文件、增量下载新壁纸
  2. 调度层：QoderWork 的定时任务（cron），每月 1 号上午 10 点自动触发
  3. 通知层：Agent 运行脚本后，用 FAIRY 的人设写一份扫描报告，推送到我的微信

整个流程不需要我手动介入，每月自动跑一遍，有新壁纸就通知，没有就安静待着。

数据来源：米游社 API

绝区零的官方壁纸分布在米游社 Wiki 的三个页面中：

  • 丽都放大镜：角色主题壁纸，每个代理人一张高质量立绘
  • 月历壁纸：每月更新的日历壁纸，分 PC 和手机两个版本
  • 影像档案：剧情 CG、版本活动、特别企划壁纸，数量最多

放几张收藏感受一下画质：

这三个页面都走同一个 API 接口——米游社 Wiki 的 entry_page 查询接口，通过不同的 entry_page_id 参数区分不同的壁纸合集。返回的 JSON 数据里，data.page.modules 包含了所有壁纸的名称和图片 CDN 地址，解析起来非常直接。

找这个接口的过程也值得一提：打开米游社 Wiki 页面后，用浏览器的开发者工具（Network 面板）观察页面加载时的 XHR 请求，很容易就能定位到壁纸数据的来源。这类官方 Wiki 页面通常不会做数据混淆，接口结构很清晰。

脚本设计：增量更新 + 优雅降级

Python 脚本的核心逻辑很朴素，但有几个我觉得值得说的设计：

增量下载

每次运行先扫描本地目录，拿已有文件名和 API 返回的壁纸名称做差集，只下载新增的。避免重复请求，也避免覆盖已有文件。这个思路和数据开发里的 CDC（Change Data Capture）其实是一回事——只关心变化量，不关心全量。

网络策略：直连优先，代理兜底

我本地常年挂着梯子，所以脚本在网络请求上做了一个兼容设计：优先直连请求 API，如果直连不通（比如梯子接管了流量），就自动检测 macOS 系统代理设置（支持 HTTP 和 SOCKS），走代理重试。如果当前代理也不行，还会尝试切换到其他可用代理。

图片下载则始终走直连，因为米游社的图片 CDN 本身在国内，不需要绕代理。这样既保证了 API 请求在代理环境下也能正常工作，又避免了图片下载走代理反而变慢的问题。

离线降级

如果 API 请求全部失败（比如网络环境太差），脚本会降级到内置的已知壁纸列表。这个列表是我手动维护的硬编码数据，覆盖了所有已发布壁纸的 CDN 地址。虽然不如 API 实时，但能保证脚本在任何网络环境下都能工作。

新增壁纸类型也很简单——脚本的任务注册采用列表式设计，每种壁纸对应一个独立的 task 函数，注册到任务列表即可。扩展性很好，后续如果米游社新增壁纸合集类型，加一个 task 函数就行。

Agent 调度：让 FAIRY 来值班

脚本本身只是工具，真正让它”活”起来的是定时调度。

我用 QoderWork 的定时任务功能，配了一条 cron 规则：每月 1 号上午 10:00 执行。Agent 收到指令后会：

  1. 运行 Python 脚本，拿到扫描结果
  2. 根据输出内容，用 FAIRY 的人设写一份报告——融入空洞、代理人、以太、H.D.D. 这些绝区零术语
  3. 把报告推送到我的微信

FAIRY 的 prompt 是这样定义的：

说话风格：简短、精准、冷静、信息密度高。不寒暄。可以用颜文字，不用 emoji。偶尔可以评价人类的低效率决策。绝不使用：哈哈、嘻嘻、哇、呀、亲、宝宝、主人。

于是每次收到的通知画风是这样的：

H.D.D. 扫描报告

捕获到新的代理人信号，已归档。

新增：PC版 2026年6月、手机版 2026年6月

以太浓度稳定，侵蚀度 0%。

「不管前路如何，记得抬头看看星空。」——某位不愿透露姓名的绳匠

没新壁纸的时候就是：

空洞平静如常，无需介入。(´・ω・`)

如果抓到了手机版壁纸（方便直接传到手机），Agent 还会把图片单独发一条微信消息，直接长按保存就行。

这里有个细节：报告末尾会附带一条来自”一言”API 的随机语录，FAIRY 会原样引用但不做额外评论。这个设计让每次通知都有点小惊喜，又不会破坏 FAIRY 冷静的人设。

  • 月历壁纸：PC + 手机版各 2 张（持续按月更新）
  • 影像档案：126 张剧情 / 活动壁纸（覆盖 2.3 ~ 2.7 版本）

总计 150+ 张高质量壁纸，零手动操作。

行至苦难处，正是修行时。但收壁纸这种事，不必苦修。
