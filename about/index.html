我是谁

赵晨尘，新疆大学软件工程本科毕业（2020-2024），大数据开发工程师。曾就职于中邮数智（西安）科技有限公司（通用技术集团下属央企），从事大数据平台开发与数据治理工作。

大学期间 GPA 3.4/5（专业前 15%），拿过蓝桥杯省赛二等奖、互联网+省赛铜奖，还当过十佳社团会长和深圳科创学院驻校科创助理——总之是一个闲不住的人。

做过什么

此前主要跟数据打交道，日常穿梭于 Spark、Doris、Flink CDC、Airflow、DolphinScheduler 这些组件之间。参与过的项目包括：

  • 数据中台：用 Spark SQL 和 Scala 完成数据开发，基于 Datahub 构建字段级数据血缘系统，SQL 调优是家常便饭
  • 基础平台建设：辅助架构师做大数据平台迁移，从 Scala 版本升级、集群数据校验到 Airflow 任务迁移，全链路参与
  • 业财数据建设：独立负责大宗贸易模块，用 Flink CDC 实时接入数据到 Doris，还手搓了一个任务调度组件来替代手工配置
  • 业财系统数智化：财务侧报表设计与开发，Spark + Doris 混合架构

技术栈涵盖 Java / Scala / Python / SQL，熟悉 Hadoop 生态（Hive、Kudu、Yarn）、实时计算（Flink CDC）、以及各类关系型数据库（PostgreSQL、MySQL、Oracle）。持有中级软件设计师证书，英语 CET-4，能流畅阅读英文技术文档。
